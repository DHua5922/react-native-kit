# Link

Url to go to when clicked on.

## Import

```jsx
import { Link } from "react-native-kit";
```

## Examples

```jsx live
function Example() {
  return (
    <Link type="info" link="https://reactnative.dev/">
      React Native Link
    </Link>
  );
}
```

## Props

:::note
Include all props from [Div](/docs/Div)
:::

| Name   | Type     | Default | Description                  |
| ------ | -------- | ------- | ---------------------------- |
| `link` | `string` |         | url to go to when clicked on |
