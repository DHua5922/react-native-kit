# Input.Search

## Import

```jsx
import { Input } from "react-native-kit";
```

## Examples

```jsx live
function Example() {
  const [text, setText] = useState("");

  return (
    <Input.Search
      placeholder="Enter text for search here"
      value={text}
      onChange={(text) => setText(text)}
    />
  );
}
```

:::note
