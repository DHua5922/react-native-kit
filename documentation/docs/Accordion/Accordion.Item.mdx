# Accordion.Item

Event key will be used for expanding or collapsing body.

## Import

```jsx
import { Accordion } from "react-native-kit";
```

## Props

| Name       | Type     | Default | Description                                            |
| ---------- | -------- | ------- | ------------------------------------------------------ |
| `eventKey` | `string` |         | Key that will be used for expanding or collapsing body |
