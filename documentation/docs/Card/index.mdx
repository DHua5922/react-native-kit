# Card

## Import

```jsx
import { Card } from "react-native-kit";
```

## Examples

```jsx
function Example() {
  return (
    <Card>
      <Card.Header>Card Header</Card.Header>

      <Card.Body>
        <Card.Title>Title</Card.Title>
        <Card.Subtitle>Subtitle</Card.Subtitle>
      </Card.Body>
    </Card>
  );
}
```

## Props

:::note
Include all props from [Div](/docs/Div)
:::
