# Row

Show children horizontally.

## Import

```jsx
import { Row } from "react-native-kit";
```

## Examples

```jsx
function Example() {
  return (
    <Row>
      <Div type="danger">
        <Text>View 1</Text>
      </Div>
      <Div type="success">
        <Text>View 2</Text>
      </Div>
    </Row>
  );
}
```

## Props

:::note
Include all props from [Div](/docs/Div)
:::
