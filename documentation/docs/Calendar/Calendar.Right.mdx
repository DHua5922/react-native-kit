# Calendar.Right

## Import

```jsx
import { Calendar } from "@dhua5922/react-native-kit";
```

## Basic Example

```jsx live
function Example() {
  return (
    <>
      <Calendar.Right />
      <Calendar.Right>{">"}</Calendar.Right>
    </>
  );
}
```

## Props

:::note
Include all props from [Pressable](https://reactnative.dev/docs/pressable)
:::

| Name      | Type                   | Default | Description                                              |
| --------- | ---------------------- | ------- | -------------------------------------------------------- |
| `onPress` | `(date: Date) => void` |         | Callback fired when pressing button to go to next month. |
