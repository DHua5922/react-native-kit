# Div

Nest components or text.

## Import

```jsx
import { Div } from "@dhua5922/react-native-kit";
```

## Examples

```jsx live
function Example() {
  return (
    <Div type="success">
      Hello World!
      <Div>Div</Div>
      <Text underline bold>
        Text <Text>Embedded Text</Text>
      </Text>
      <Div>
        Div <Text>Text</Text> Div
      </Div>
    </Div>
  );
}
```

## Props

:::note
Include all props from [Text](/docs/Text) or [View](https://reactnative.dev/docs/view)
:::
