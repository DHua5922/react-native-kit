# Tab

## Import

```jsx
import { Tab } from "@dhua5922/react-native-kit";
```

## Props

:::note
Include all props from [Button](/docs/Button)
:::

| Name       | Type              | Default | Description                                    |
| ---------- | ----------------- | ------- | ---------------------------------------------- |
| `title`    | `React.ReactNode` |         | Tab label.                                     |
| `eventKey` | `string`          |         | Key that will be used for toggling active tab. |
