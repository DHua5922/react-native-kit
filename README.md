# react-native-kit

A reusable React Native toolkit that provides UI components, hooks, and helpers for mobile apps.

## Installation

Enter `yarn add @dhua5922/react-native-kit`.

## Package Contents

The published package includes only the compiled `dist/` output and type
definitions.

## Documentation Site

[https://www.huadylan.com/react-native-kit/](https://www.huadylan.com/react-native-kit/)

## How To Run Documentation Site

Enter `yarn start`.
